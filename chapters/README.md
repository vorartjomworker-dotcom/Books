# Главы

Для каждой активной главы создаётся отдельный каталог `CH01`–`CH27`.

Рекомендуемая структура главы:

- `registry/` — двуязычный канонический реестр;
- `batches/` — непересекающиеся партии перевода;
- `figures/` — локализованные иллюстрации и реестр изображений;
- `reports/` — отчёты проверок и манифесты.

Принятые версии не перезаписываются.
