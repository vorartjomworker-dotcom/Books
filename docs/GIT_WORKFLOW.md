# Git-конвейер перевода ML4T

## Источник и контрольная копия

- До отдельного решения о миграции Google Drive остаётся каноническим рабочим источником.
- `main` содержит проверенные контрольные снимки, манифесты и историю изменений.
- EPUB и визуальный PDF не добавляются в Git. Для них хранятся только идентификаторы и SHA-256.
- Экспорт из Drive не перезаписывается молча: новый снимок получает новую версию или датированный манифест.

## Ветки и партии

- Одна глава и одна партия — одна ветка вида `translation/chNN-bXXXX-bYYYY`.
- Одна партия — один Pull Request в `main`.
- В Pull Request нельзя смешивать главы или несвязанные административные изменения.
- Перед объединением должны пройти автоматические проверки и глубокий QA партии.

## Обязательные проверки

1. `block_id` уникальны, принадлежат нужной главе и образуют полный непрерывный диапазон.
2. Статусы входят в разрешённый набор.
3. Для финальных статусов исходный и переводной тексты заполнены, если соответствующие столбцы распознаны.
4. Реестры ошибок читаются, а их `error_id` уникальны и имеют корректный формат.
5. Контрольные суммы экспортных снимков совпадают с манифестом.
6. EPUB и исходный PDF отсутствуют в отслеживаемом дереве `source/`.

## Условие объединения

Партия объединяется с `main` только после статуса `QA_PASS`, закрытия блокирующих ошибок и успешного задания `Registry validation`.
